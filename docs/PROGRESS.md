## 한 줄 소개
대부도를 배경으로 한 가벼운 웹 미니게임 모음. 정체성: "대부도와 함께하는 로컬 어드벤처, 지역 파트너십으로 트래픽을 높여가는 중독성 있는 게임" (안건문서 참조).

## 운영 정보
- 사이트: https://daebugame.com (Vercel 자동 배포, GitHub 웹 업로드로 반영)
- 공용 기능: 이벤트 랭킹(닉네임+연락처, 연락처 비공개), 헬로 신전(게임별 왕좌·명예의 전당), 관리실(랭킹 관리·게임 문구 설정), 카카오톡 공유 카드, PWA(홈 화면 설치), GA4 이벤트 추적
