# 안건: 「헬로 대부도 오락실」 프로젝트 정식 등록

## 1. 배경

헬로대부도 재건 프로젝트(LOCA 콘텐츠엔진/SCOUT/STORY/PICK)는 별도 프로젝트 지식방에서 계속 진행 중이며, 이 안건은 그것과 **리소스가 완전히 분리된 독립 실험 트랙**에서 출발했다.

기존 콘텐츠 SEO 모델(블로그 글 + 쿠팡 제휴)에만 사고가 갇혀 있다는 자각에서 시작해, 완전히 다른 채널(캐주얼 게임)로 트래픽을 모으고 그 채널 자체에 지역 자영업자를 광고주로 유치하는 모델을 탐색했다. 사전 조사 결과, 미니게임 컨셉이 3시간/주 예산 안에서 가장 현실적인 파일럿으로 채택되었고, 그 첫 결과물로 **헬로버드**(Flappy Bird 장르 리스킨)를 프로토타입 개발했다.

## 2. 목적 / 핵심 가치

프로젝트의 1차 목표는 **"중독성"** — 단순하지만 자꾸 다시 찾고 싶어지는 캐주얼 게임 경험이다. 이 중독성 안에 다음 세 가지 사업적 키워드가 내포되어 있다:

- **대부도**: 배경·장애물·스토리 전체가 실제 대부도 지역성(스테이션 = 실제 지명)에 기반
- **관광**: 게임을 통해 대부도 명소를 자연스럽게 노출·인지시키는 간접 관광 홍보 효과
- **광고 섭외**: 지역 소상공인이 게임 내 공중부양 상가(광고) 형태로 입점, 실질적 광고 매출원 확보

## 3. 현재까지 진행 상황

### 3-1. 완성/확정된 것
- 게임 컨셉: 헬로(갈매기 마스코트)가 대부도 하늘을 여행하는 세로 화면 캐주얼 게임
- 아트 파이프라인 확립: 캡+반복타일 구조로 장애물 제작, 배경 4레이어(하늘/원경/중경/근경) 규격 확정 — **스테이션 하나 추가 시 동일 사이즈 템플릿에 그림만 채워 넣으면 되는 구조**
- 에너지 시스템(하트 3개), 조정 패널(배경 위치·블러·스크롤 속도, 장애물 크기·간격 등 실시간 조정 가능), 난이도 곡선(스테이션 초반 쉬움 → 후반 어려움) 구현
- 1번째 스테이션 **"방아머리"** 방아머리 해변 완성 단계 — 실기기(모바일 브라우저) 테스트 가능한 프로토타입으로 배포 중

### 3-2. 설계 확정, 구현 대기
- 공중부양 상가(광고) 시스템: 상점 진입 시 화면 전환 + RPG풍 대사창(예: "대부도 최고의 옥수수찐빵집! 용사여, 이 찐빵을 드시오...") → 에너지 완전 회복. 상점별 데이터(이름/이미지/문구/대사/회복량)만 추가하면 되는 구조로 설계
- 연출 효과: 5의 배수 통과마다 마일스톤 팝업, 피격 시 화면 흔들림+붉은 플래시
- 효과음: 1차는 코드 합성음, 추후 라이선스 확인된 실제 음원으로 교체

### 3-3. 계획된 스테이션 확장
시화방조제 → 방아머리(완성) → 구봉도 → 바다향기테마파크 → 탄도항 순으로, 실제 대부도 동선을 따라 난이도를 배치할 계획. 바다향기테마파크는 난이도를 오히려 낮추고 광고(공중부양 상가)를 집중 배치하는 "보너스 구간"으로 설계.

## 4. 프로젝트 구조

- 별도 오락실 허브 페이지(가칭 「한판만 대부도」)를 신설하고, 완성되는 캐주얼 게임을 하나씩 카드로 등록
- 헬로버드가 첫 번째 입점 게임
- 대부도타임/헬로대부도 양쪽 사이트에서 오락실 페이지로 링크를 걸어 상호 트래픽 순환 구조 형성 (오락실 → 본 사이트, 본 사이트 → 오락실 양방향)

## 5. 리소스 / 제약

- 헬로대부도 재건 프로젝트의 3시간/주 예산과는 **별도 트랙**으로 운영 — 상호 리소스 침범 금지 원칙 유지
- 이번 파이프라인(배경 4레이어 규격, 캡+타일 조립 방식, 조정 패널·에너지 시스템 등 공용 뼈대)은 **다음 캐주얼 게임 제작 시 재사용 가능** — 지속 개발의 현실적 전제조건

## 6. 이번 회의에서 결정이 필요한 사항

1. **프로젝트명 확정** (추천안: 한판만 대부도 / 대부도 무한루프 / 대부도 재접속 / 헬로오락실 / 대부도 딴짓타임)
2. 오토컴퍼니 정식 프로젝트로 등록 여부
3. 방아머리 스테이션 이후 우선순위 — (a) 나머지 4개 스테이션 확장 vs (b) 광고 시스템(RPG 대사창) 구현 vs (c) 오락실 허브 페이지 자체 구축, 착수 순서 결정

## 7. 최종 결정사항 (회의 결과)

**① 프로젝트명**: 헬로 대부도 오락실

**② 정체성 / 다짐**: "대부도와 함께하는 로컬 어드벤처, 지역 파트너십으로 트래픽을 높여가는 중독성 있는 게임"

이 정체성은 앞으로의 판단 기준이 된다:
- 재미 요소들 사이에서 우선순위를 정할 때, **지역 파트너십(광고·상가 노출)과 연결되는 기능을 우선**한다 — 공중부양 상가/RPG 대사창 시스템은 부가 기능이 아니라 정체성의 핵심으로 재확인됨
- 앞으로 만드는 모든 게임은 "지역 상가를 자연스럽게 노출시킬 자리가 있는가"를 기획 단계에서 먼저 검토한다

**③ 오토컴퍼니 정식 프로젝트 등록**: 확정

**④ 창의적 방향 — 기존 보유 API 연동**: 이미 LOCA에서 확보된 API(기상청 날씨 API, 국립해양조사원 조위/물때 API 등)를 게임 메커닉에 직접 녹이는 방향을 채택. 예: 오늘의 실제 날씨에 따라 배경/장애물이 변하는 날씨 연동 게임, 실제 물때 값에 따라 난이도나 배경이 달라지는 게임. 이는 LOCA 엔진 자산을 오락실 프로젝트에서도 재활용한다는 점에서 리소스 효율이 높고, "실제 대부도의 지금 이 순간"을 게임에 담는다는 점에서 정체성(②)과도 직접 연결됨. 향후 신규 스테이션/신규 게임 기획 시 후보 컨셉으로 계속 검토.

**⑤ 방아머리 스테이션 이후 우선순위**: 스테이션 확장보다 **게임 완성도를 먼저 끌어올리는 것을 우선**한다 — 헬로버드 1개를 제대로 완성(연출·효과음·광고 시스템까지)한 뒤에 스테이션을 늘려간다.
